## 📂 Proyectos Destacados

### 🏗️ Pipeline Big Data con Arquitectura Medallion (Sector Minero)
Implementación de Arquitectura Medallón (Bronze, Silver, Gold) en Databricks con PySpark para procesar telemetría de una planta minera de hierro y sílice. Resolvió 3 requerimientos críticos de control de calidad y eficiencia de reactivos, con integración continua entre Databricks y GitHub.
`Databricks` `PySpark` `SQL`

### 🤖 Sistema Automatizado de Extracción y Procesamiento de Datos
Agentes de IA en Python + OCR/NLP para transformar resoluciones regulatorias no estructuradas en datos tabulares en SQL Server. Desplegado en Docker sobre Linux. **Redujo el tiempo de carga manual en 99% (4 horas → 2 minutos).**
`Python` `OCR` `NLP` `Docker` `SQL Server`

### 📡 Sistema de Telemetría IoT y Asistente Virtual
Prototipo IoT para ingesta de inventario en tiempo real, sincronizado vía Power Automate, con un agente de IA conversacional en WhatsApp (NLP + Azure Speech-to-Text) para consultas ejecutivas.
`IoT` `Power Automate` `NLP` `Azure`

### 📇 Generador Automático de Tarjetas en Excel
Automatización con lógica en Python y frontend ligero en React empaquetado con Tauri. Reemplaza el llenado manual de un formulario que tomaba tiempo considerable por trabajador (hasta 3 tarjetas c/u) y generaba errores de formato al perder consistencia entre tarjetas. **Redujo el tiempo de la tarea en más de un 70% y eliminó los errores de formato.**
`Python` `React` `Tauri`

### 🧮 Sistema de Gestión y Conteo de Andamios
Aplicación desarrollada en mi rol de Apoyo Logístico para calcular de forma autónoma la cantidad de cuerpos de andamios y estimar el stock necesario según la disponibilidad actual en la ubicación. Lógica en Python, frontend en React empaquetado con Tauri.
`Python` `React` `Tauri`

### 🚙 Vehículo IoT Anticolisión
Prototipo sobre chasis tipo tanque con microcontrolador ESP32, sensores de proximidad y luces LED que funcionan como sistema anticolisión, comunicado vía protocolo MQTT.
`ESP32` `MQTT` `IoT`

### ✅ HaBit — Habit Tracker (Electron + Claude)
Aplicación de seguimiento de hábitos construida en JavaScript/Electron, desarrollada como prueba práctica de las capacidades de Claude para desarrollo de software. Totalmente funcional y en mejora constante, adaptada a mis propias necesidades de uso diario, con miras a publicarla eventualmente.
`JavaScript` `Electron`

### 🚧 Generación de KPIs desde Simulación de Flota CAEX (En desarrollo)
Sistema end-to-end que simula un flujo continuo de datos de una flota de 5 camiones CAEX en Python, ingeridos vía Kafka y procesados en PySpark bajo arquitectura Medallion (Bronze, Silver, Gold). Incluye un módulo independiente para gestión de cambios de turno, con diseño desacoplado que facilita extenderlo a futuro.
`Python` `Kafka` `PySpark` `Medallion Architecture`
